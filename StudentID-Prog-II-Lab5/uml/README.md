# UML diagrams

The `.mmd` files are editable Mermaid source files. The `.png` files are rendered copies for submission and review.

The diagrams describe the final Java packages and enums:

- class-diagram: classes, inheritance, aggregation, composition, and association.
- object-diagram: one example colony object and its connected objects.
- mission-state: MissionState transitions.
- mission-sequence: mission submission, validation, execution, and release.
- oxygen-leak-sequence: oxygen leak response alternatives.
- environmental-sequence: dust storm and communication disruption behavior.
- use-case-diagram: operator interactions with the system.
